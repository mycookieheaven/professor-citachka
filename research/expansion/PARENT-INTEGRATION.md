## Spanish and Russian homepages (/, /es, /ru)
- The homepage and the site header exist in three languages, each at its own address: English at `/`, Spanish at `/es`, Russian at `/ru`.
- The three pages render from **one component** (`src/components/HomeContent.tsx`) reading three data files (`src/data/i18n/{en,es,ru}.json`). This is the structural point: a copied-and-translated page drifts, and within a wave or two the translations stop matching the original. One layout plus three dictionaries cannot drift.
- The switch is built from ordinary links, so each language is bookmarkable and shareable, the pages work with JavaScript disabled, and `hreflang` alternates are declared in metadata. The document `lang` attribute is set per page.
- Scope boundary, recorded so it is not overclaimed later: this covers the homepage and the site header. **The 920 lessons are English only.** Translating lesson content across eleven subjects is a different order of work from translating interface chrome, and it has not been done.
- Tests exist for the failure modes that make a translation worse than none: a locale silently falling back to English (each page is asserted not to contain the other languages' strings) and a dictionary missing entries (every locale is asserted to have the same paragraph count and no empty strings).
